Nuvio Desktop (Linux)

Signed Flatpak builds of the Nuvio Desktop Linux port. Current stable release: 1.16.2 (source 033e6157e554, OSTree commit 8ed3e1fb5544).

Install

flatpak install --user https://iamslokker.github.io/NuvioDesktop-Linux/flatpak/com.nuvio.media.desktop.flatpakref

Or add the repository, then install from it:

flatpak remote-add --user --if-not-exists nuvio https://iamslokker.github.io/NuvioDesktop-Linux/flatpak/nuvio.flatpakrepo
flatpak install --user nuvio com.nuvio.media.desktop

Updates then arrive through flatpak update, GNOME Software/Discover, or the app's update prompt. The GNOME Platform runtime comes from Flathub.

Moving from a downloaded .flatpak bundle

Bundles from earlier releases were not linked to this repository and never update. Uninstall once (your profile in ~/.var/app/com.nuvio.media.desktop is kept), then install as above:

flatpak uninstall --user com.nuvio.media.desktop
flatpak install --user https://iamslokker.github.io/NuvioDesktop-Linux/flatpak/com.nuvio.media.desktop.flatpakref
